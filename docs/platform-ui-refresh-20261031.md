# 桌面界面统一优化

本批按用户要求调整全平台审美与布局，使用百林科品牌青色、白色内容区、浅灰背景和深色文字。共享规范位于 `web/src/platform/theme.css`，业务页的普通文字、边框、背景引用相同变量；状态提示保留成功、警告和错误的区别。基础样式与模块样式共同维护，避免新增页面各自定义一套配色。

- 顶栏合并品牌、资料搜索和账号操作，减少重复工具栏；保留用户指定的消息、反馈位置及工作台管理中心卡片。
- 应用入口采用紧凑卡片；统一页面标题、侧栏选中态、表格、按钮、表单及对话框的尺寸和间距。
- 公盘、档案查询、流程和实物借还使用功能名称作为主标题；导入、扫描、实物、通知维护移除会撑宽内容区的固定最小宽度和重复外边距。
- 新增可复用的 `EmptyState.vue`，用于工作台、公告、待办、消息、反馈、公盘和档案查询的空状态；不填充虚构业务数据。
- 模块切换后回到页首，避免沿用上一页长列表的滚动位置。长目录和表格在各自区域滚动；桌面窗口仍保留全部操作。
- 登录页保留公司白色LOGO和系统大标题，表单使用同一品牌色；Office编辑器和受控阅读的宿主面板沿用统一规范。独立打印页仅调整屏幕工具栏和背景，打印正文及媒体规则保持原有规则。
