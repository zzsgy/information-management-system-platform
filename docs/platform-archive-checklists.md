# 档案台账、电子清单与附件

2026-11-03，依据用户本轮完整需求实施。所有部门、所有档案类别使用同一套档案盒台账和电子清单格式；所属部门仍是每条档案的属性及管理权限范围。

通用台账模板适用于行政档案、销售合同、采购合同、项目合同、质量文件、工作记录等全部类别。修改类别无需更换模板，原台账字段值继续保留。档案盒和文件的模板仍按对象类型区分；历史专用模板保留兼容，不自动改写既有目录。

## 使用顺序

1. 在档案管理页面点击“档案登记”创建单条台账，或点击“批量导入”按原18列 Excel 台账登记档案盒。该入口导入台账信息，不导入电子文档。
2. 点击档案盒行的“电子清单”，选择 XLSX 清单，读取并预览，确认后写入该盒。
3. 选择清单所列文档，可批量上传。先检查对应结果，再确认上传。电子文件逐份检测，Office 文档转换为受控阅读表示。
4. 展开档案盒查看清单及附件。完成台账、原件和所有电子文档的人工核对后，点击“归档审批”，提交既有的独立审批路线。

顶部保留“批量导入”“档案登记”两个按钮。盒行保留“修改”“删除”“归档审批”“电子清单”。附件行保留“查看”“下载”“打印”“上传”“删除”。

## 台账展示

- 档案编号、档案名称、存放位置、保存类型、保存份数、保密级别、有效期和档案状态分别展示。
- 原台账已有编号时展示原编号，并保留系统唯一盒号。清单填写存放编号时，两种编号均可对应本盒。
- 柜号、列号、层号组合为 `13柜 / A列 / 3层`，在一列展示。修改位置时同步随盒保管的实物位置并追加位置事件；借出原件未归还时不能移动。
- 原台账状态与系统归档状态分别展示。“正常”来源值不能代替归档批准。原台账到期日保留，系统保管期仍按实际存档日及日历年计算。
- 盒条目默认折叠，按需展开。清单按数字序号升序排列，例如 `1、2、10`。
- 刷新按钮位于列表底部，总数与分页位于右下方。

## 电子清单格式及份数

原六列表头：`存放编号、序号、日期、存放内容、存档份数、备注`。也支持省略“存放编号”的五列表头；前置空白列不会改变对应关系。

合同清单另支持八列：`存放编号、序号、日期、签订主体、存放内容、合同编号、存档份数、备注`。按中文表头名称对应，列顺序可以调整。存放编号、签订主体、合同编号可省略或留空，其他五列表头须存在。未知、重复或缺失的表头会明确指出字段名，不能静默丢弃。

- 序号须为唯一正整数，名称不能为空，纸质存档份数为正整数。Excel 将整数保存为 `1.0` 时可以识别，不会截断真实小数。
- 日期支持 Excel 日期值及 `2025.4.17`、`2025-04-17`、`2025/4/17` 等文本日期。
- 仅填写年份（如普通数值 `2021`）时，单独保留文件年份，不生成月日，也不当作Excel日期序号转换。完整日期仍作为形成日期保存。
- 签订主体、合同编号完整存入文件目录扩展字段，预览及展开清单均显示，文件详情可维护。合同编号按文本保留，例如 `0001-A`。签订主体是合同主体文本，不要求关联人员账号。
- 存放编号填写时须为当前盒号或原档案编号。错盒时同时显示原表行号、填入编号及当前盒号，不能把另一盒清单静默挂入当前盒。
- **存档份数记录纸质副本数量。即使纸质档45份，同一内容只登记一条清单、上传一份电子文件。**
- 清单使用单一工作表，不接收公式或外部链接。每次最多1000条，每盒最多1000条有效清单，超过时明确提示分盒，不能静默漏显。
- 已有序号不会被再次导入覆盖；删除草稿后原编号与历史仍保留。

## 文件对应与版本

- 推荐文件名 `1_房屋租赁合同.docx`。序号与名称同时存在时，两项都一致才自动对应。
- 只有名称时，必须唯一对应。全半角、大小写、空白和常用文件扩展名会统一比较。
- 序号冲突、同名、未匹配或多个文件指向同一条目时，不猜测，必须在下拉列表中明确选择或移除。
- 一条清单一次只能对应一份电子文件。替换操作保留旧原件、旧PDF和目录修订。
- 支持 PDF、DOCX、XLSX、PPTX、DOC、XLS、PPT。WPS与Office均可保存这些常用格式；本次实际验证的是这些格式的服务器处理链路，未声称逐台验证所有WPS/Office客户端版本。
- 浏览器每份上限50 MB，每批最多100份。转换失败保留原件并显示失败原因，可以“重新处理”，不能把上传100%显示成处理成功。

## 审批及使用边界

直接维护、导入清单和替换电子文件在盒草稿阶段进行。已归档资料的修改与删除沿用更正、撤下流程，保留历史和在途借还责任。

整盒送审冻结本次清单的目录修订和PDF版本。申请人须明确确认人工检查；技术检测或转换成功不替代人工检查和独立审批。审批人可逐份阅读冻结候选。驳回时盒及本次电子条目回到草稿；批准时同事务发布盒和冻结的清单文档。

阅读使用统一连续阅读器，保留本人水印、逐次鉴权和保护检查。下载、打印继续核验已有独立批准及打印额度；按钮禁用时提供原因，不通过原件直链绕过。
