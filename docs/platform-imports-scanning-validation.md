## 关键场景

台账验证整批预检错误不写业务、确认时再次鉴权、模板变更失效、并发及重复提交只创建一次、原编号映射、向已有盒新增、未发布撤回、本人待复核流程撤回、拒绝撤回已发布和外部引用，以及部门上下级循环、员工凭据私有投递。撤销部门职责后，旧批次先从列表及统计中排除。

扫描验证真实分片和摘要、专用身份范围、服务有效期、签名防重放、错设备、接收过程中停用、检测进程不可用后重试、无害恶意标记被隔离、双副本异常拒绝、服务器实测页数与人工核对一致、返工后旧阅读会话失效、旧上传轮次失效、特殊原件独立批准、暂停处置及批准恢复、原件交接归还、暂存清理与关闭前置条件。技术接收和人工质检均不能代替正式归档审批。

浏览器从真实 Excel 上传、检测、预检到员工创建贯通；档案确认及撤回、个人水印逐页检查、人工质检、扫描清单登记、原件取出与归还均经页面操作。正式 `scan-agent.cjs` 使用本实例 CA 校验证书，通过 HTTPS 签名接收实际 PDF，重跑同一清单仍只有一个回执和一个 PDF。测试验证源文件保留、路径越界拒绝及清单独占锁；IT 页面停用后，设备接口立即拒绝访问，既有回执仍在。服务身份不能访问员工 API 或档案内容。

## 本轮发现并修复

1. 既有通知领取查询可能先扫描全部历史通知再执行复杂授权函数，实测只读查询约 9.3 秒，并触发服务十秒语句上限。现改为先锁定单个到期候选，再按固定通知主键复核权限；失效候选有界取消，原租约未知结果保留。本人列表也先排除已取消历史。新增 1500 条取消历史，在数据库三秒语句上限内验证列表与领取，并完整重跑 19 项通知用例。
2. 导入列表在分页统计前过滤当前授权范围；设备选择器改为 SQL 内批量权限过滤，消除逐设备重复查询。导入批次与逐行结果分别分页。
3. 检测途中停用、返工纠正及当前候选保护在写事务内再次核对；检测失败保留明确批次事件。扫描代理增加同一清单独占锁。
4. 截图检查修正导入筛选复选框继承整行输入框尺寸的问题，最后通过真实页面复核。

测试过程中的 XLSX/PDF 合成页数、岗位交接唯一约束及 HTTP 201 状态预期错误均已按真实契约纠正。常规文件保护测试最初受沙箱临时目录 ACL 限制，在可执行实际 Windows 私有目录保护的环境重跑后通过；没有放宽生产目录权限或数据库超时来绕过检查。
