# 档案盒台账字段筛选

2026-11-04：按用户要求，将列表业务列补齐为对应筛选条件，字段名称与输入控件同行，筛选区分行留出间距。

| 列或信息 | 筛选控件及匹配方式 |
| --- | --- |
| 档案编号 | 文本包含匹配，同时匹配原台账编号与系统盒号 |
| 档案名称 | 文本包含匹配 |
| 存放位置 | 文本包含匹配列表显示的柜、列、层组合；没有三段数据时匹配原登记位置 |
| 保存类型 | 下拉精确匹配，选项来自全部获权台账，不局限当前页，不预设一组固定类型 |
| 保存份数 | 最少至最多的数值范围，包含端点，可以只填一端 |
| 保密级别 | 一般、重要保密、核心保密下拉选择 |
| 有效期 | 分为保管年限下拉和到期日期范围；日期包含端点，永久保管没有到期日期 |
| 档案状态 | 保留草稿、归档审批中、已归档下拉选择 |

原有综合检索继续提供关键词和台账描述搜索。各条件按“同时满足”组合，搜索和重置回到第一页，重置清空全部筛选条件。范围倒置或无效日期在查询入口提示参数错误，不改变任何台账数据。

## 查询与权限

后端 `ArchiveCatalogService.boxes` 在原有维护权限范围内先筛选、计数再分页，前端不只过滤当前页。模糊搜索对 `%`、`_` 等字符按用户输入的文字匹配。新增的 `GET /api/v1/archive/box-filter-options` 沿用同一维护权限，其他部门的保存类型不出现在下拉选项中。选项在进入页面、登记、导入及维护后刷新，搜索翻页不重复加载选项。

源文件为 `ArchiveLedger.vue`、`ArchiveCatalogService.java`、`ArchiveController.java`，无需数据库结构迁移。
