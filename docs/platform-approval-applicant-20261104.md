# 审批详情补齐借阅人信息（2026-11-04）

用户反馈：行政账号提交借阅，另一账号办理审批时，窗口没有显示借阅人，无法判断申请来源。

## 原因与修改

`GET /api/v1/workflow/steps/{id}` 原先仅提供 `workflow.applicantId`，网页没有解析和展示申请人身份。本次在既有节点鉴权后，增加只读 `applicant` 摘要：姓名、工号、申请时所属部门、申请时间。审批人和原申请人沿用原有可见范围，无关人员不能通过该接口查询。

姓名和工号来自流程记录绑定的账号；借阅部门及时间来自原借阅批次。其他审批的部门来自原路线快照、时间来自流程创建记录。响应只包含明确列出的身份摘要，不包含密码、邮箱或其他人员管理资料。

电子借阅、纸质借阅及续借共用审批窗口，均在借阅用途前显示“借阅人信息”。归档、目录变更及基础开放的同类审批窗口显示“申请人信息”。部门、时间不是由前端填写，已有申请也能直接显示，无需重新提交或补录。

未改动审批节点、角色分配、借阅授权、实物交付或审批意见规则；无需新增数据库迁移。
