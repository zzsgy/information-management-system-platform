# 受批下载和打印开发及验收

本批次延续独立平台、独立新库及电脑端界面，增加档案电子下载和打印。旧系统、旧数据库和附件不切换；未接入正式业务数据。前一批的电子查看和续借规则继续生效。

## 已接通的业务链路

1. **动作分别批准**：电子借阅可以明确选择查看、下载、打印，三种动作不互相推导。逐文件动作固定在审批快照中，按原批次最高等级和所属部门走既定必要路线。审批页显示具体动作、打印页码与累计批准份数。目录管理、平台管理或 IT 身份均不代替正文批准。
2. **版本绑定**：申请和实际使用均绑定独立文件、当前目录修订、完整 PDF、具体批准来源及来源版本。生成后撤权、授权到期、审批来源失效或正式版本变化，都停止旧任务交付；不会偷偷换用另一条批准。
3. **水印使用副本**：原件只读。隔离 PDF 工作器将批准页以 150 DPI 栅格化后重建 PDF，姓名、工号、服务端时间、独立文件号、动作和任务标识烘入像素。页脚增加留白，保留原页底部内容；长身份字段换行。使用副本不保留文本选择、正文搜索和原矢量结构，也不携带原件脚本、附件、隐藏文本或原签名对象；不承诺原件数字签名的验证结果。
4. **单份和批量下载**：单份交付个人水印 PDF，批量交付水印 PDF 与 `manifest.json` 的 ZIP。清单包含具体修订、PDF 版本、文件号、实际成品字节数及 SHA-256；任一项失效时拒绝整个包。
5. **受控打印**：页码只能取批准集合的子集，空输入使用批准范围，默认一份。受理时锁住本人及具体授权，原子占用累计份数；同操作号重试复用原任务，不重复扣额。打印份数展开到输出页中，电脑端按固定顺序加载水印页，单独打开打印页面。结果未知、客户端失败或生成失败均不自动返还已受理额度。
6. **本人再验证**：重要保密、核心保密以及任何多文件使用，必须重新验证本人密码。五分钟一次性凭据绑定完整目录修订清单及单一动作，不能拆分清单、跨动作或跨会话使用；凭据不替代业务批准。
7. **交付记录**：成功响应前先取得库外独立刷盘回执，再记录服务端交付许可。个人历史显示文件号、任务状态、取件操作数和客户端反馈，仍有效的同会话任务可以重新打开，取件不再占用打印额度。原始文件路径、内部存储键及秘密不进入浏览器响应。

下载和打印授权不自动续期，也不重置打印额度。现有续借入口继续仅办理单独的 `VIEW` 批次；含下载或打印的批次需要重新提交明确动作申请。

## 电脑端交互

- 档案中心选择资料后“申请使用”，明确勾选动作；打印额外填写批准页码和累计份数。
- 获得具体批准后，单份或所选清单显示受批下载、受批打印入口，生成过程与实际业务批准分开显示。
- 下载在保存前核验服务端成品 SHA-256；中断、空内容或摘要不符不保存为成功文件。
- 打印页展示已展开的输出页数，提醒系统打印对话框选择一份。提交前再核验批准；后台每四秒检查当前资格，失效后撤销图像引用并清空页面，后台检查不延长登录空闲期限。
- 交付历史可以查看原任务，避免用户因关闭对话框或网络重试重新生成副本。

## 安全及资源边界

| 项目 | 当前实现 |
|---|---|
| 使用会话 | 固定本人、发起会话、授权代次和动作；最长十五分钟，且不晚于来源授权截止 |
| 文件数 | 每任务最多五十份不同文件；盒展开后同样受限 |
| 输出页数 | 下载每任务最多三百页；电脑端打印最多五十个实际输出页，包含展开的份数 |
| 异步队列 | 每人最多三个活动任务，全局最多二十个；并发检查在事务锁内执行 |
| 解析资源 | 与受控阅读共享两个子进程名额；子进程堆 256 MiB，每次调用三十秒；单页最多一千六百万像素 |
| 交付资源 | 单成品最多 128 MiB；两条交付通道，64 KiB 流式缓冲；每 1 MiB 或一秒再验当前权限 |
| 使用频率 | 十分钟内受理下载最多五十份文件、打印最多三十份文件；逐页取图和原操作重放不重复计数 |
| 输出冗余 | 派生副本写两个专用私有目录，独立刷盘和重算摘要；生成及交付还核验原件双副本 |
| 缓存容量 | 每侧已登记派生缓存最多 512 MiB；容量不足时拒绝新成品，不删除原件腾空间 |
| 缓存清理 | 使用截止及二十四小时保护期均已过后，每分钟最多十件；只删除派生库的明确随机键，保留交付及反馈元数据 |
| 失败处理 | 租约和来源在生成前后分别检查；提交结果不明时保留可能已被引用的成品，避免误删有效输出 |

权限改变后不能收回已发送的字节或已经保存到本地的副本。浏览器打印可以另存 PDF、选择多份或重复使用已经取得的页面，网页不能提供物理出纸份数的强约束。本批次的额度表示**服务端受理的授权副本份数**。

打印反馈仅接受 `SUBMITTED`、`CLIENT_FAILED`、`UNKNOWN`，来源固定为 `BROWSER_CLAIM`。`SUBMITTED` 表示已调用客户端打印流程，不能证明实际出纸。尚未接入可信打印设备，提交 `VERIFIED_PRINTED` 会被拒绝。

## 接口和部署配置

| Service API | 用途 |
|---|---|
| `POST /api/v1/archive/borrow-batches` | 明确动作、页码与批准份数的电子申请 |
| `POST /api/v1/archive/download-requests` | 用具体下载批准建立个人副本任务 |
| `POST /api/v1/archive/print-requests` | 用具体打印批准建立个人副本任务并占用份数 |
| `GET /api/v1/archive/{download,print}-requests/{usageId}` | 本人任务清单及处理状态 |
| `GET /api/v1/archive/{download,print}-requests/{usageId}/content` | 当前仍有效的水印内容；批量打印使用逐页接口 |
| `GET /api/v1/archive/print-requests/{usageId}/pages/{page}` | 当前获准的打印输出页 PNG |
| `POST /api/v1/archive/print-requests/{usageId}/feedback` | 幂等记录客户端过程反馈 |
| `GET /api/v1/archive/export-requests` | 最近五十条本人使用任务及可重新打开状态 |

创建、取件、逐页取图及反馈使用 `X-Operation-Id`；业务写入还需统一的会话与 CSRF 校验。相同创建操作号换载荷返回冲突，相同操作的重放不重复消费再验证凭据和打印份数。技术任务继续使用领域处理器接口 `FileDomainJobs`，水印模板与来源版本均保留扩展字段。

新增迁移为 `V17__archive_approved_exports.sql`，原 `V1` 至 `V16` 不改写。新增配置均在 `platform.yml` 中文说明：

- `IMS_PLATFORM_EXPORT_PRIMARY`、`IMS_PLATFORM_EXPORT_SECONDARY`：个人水印成品双目录的绝对路径。
- `IMS_PLATFORM_EXPORT_TEMP`：本次生成输出的私有临时目录。

三个目录必须相互独立，且不能与原件、账本、邮件、交付回执或阅读临时目录相互包含。缺配置、实例标记不符或副本损坏均拒绝使用。PDF 工作器继续使用既有 `IMS_PLATFORM_READING_*` 配置；运行包需要与其 `lib` 依赖一并部署。通过 `scripts/platform/build.ps1` 先构建网页、后端及独立工作器，避免仅重新打包旧网页资源。

本轮验收地址是独立的 PostgreSQL `55442` 和 HTTPS `18448`。最终后端包位于全新构建目录 `D:/tmp/ims-platform-export-final-build`，验收环境位于 `D:/tmp/ims-platform-export-20261028`，均不覆盖旧应用产物。报告和截图保存在工作区 `tmp/platform_export_20261028`，私有配置及登录秘密不写入报告。

验收完成后已停止本轮 HTTPS 和数据库测试服务，保留测试库、原件、派生测试材料和源码快照。旧系统未切换。本机采用全新输出目录完成离线 Maven 编译与打包；离线缓存未包含 `clean` 插件，因此没有将常规构建脚本入口计为已执行验证。

## 验证记录

- 导出集成测试十四项：独立动作拒绝、管理员无正文权、他人任务拒绝、水印及原件不变、并发重复提交、累计份数、批准页码、未知打印反馈、撤权及到期、换版、敏感及批量凭据、原件/成品副本异常、库外回执失败、保护失效、整包清单 SHA-256、过期派生清理。
- 原有档案、审批、授权和续借集成回归三十三项通过。
- 后端普通验证执行一百零一项通过；需要指定隔离环境的集成项目在普通验证中明确跳过，另外单独执行上述真实 PostgreSQL 集成验收。
- 独立 PDF 工作器三项通过，包含横竖版、页序、批准份数展开、中文水印、长身份换行、无隐藏表单/附件/签名对象，以及原页底部标记保留。
- 前端类型检查、正式构建及既有七项回归通过。Edge 使用 1600×1000 电脑端视口完成真实申请、五节点审批、水印下载、历史取件、打印页、他人越权、到期清页和正式撤权验收。

浏览器验收将打印按钮调用替换为可观测函数以验证过程反馈，同时导出浏览器打印排版 PDF；没有连接真实打印设备，也未验证实际出纸。测试扫描使用真实原生检测引擎与无害测试签名，保护代理事实为合成验收事实；正式病毒库、异机冗余、备份恢复、操作系统隔离与容量压测仍需部署验收。异常崩溃遗留的无引用文件需要在私有派生区做核对，本批不扫描或清理原件目录。
