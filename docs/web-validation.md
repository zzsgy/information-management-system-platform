验证日期：2026-10-19。本轮将档案模块主界面由PySide6改为Vue浏览器应用；代码在本地工作区，尚未提交或推送Git，未部署公司正式环境。

- 前端：Node24.19.0、npm11.17.0；Vue3.5.44、Vue Router5.4.0、Element Plus2.14.7、Vite8.3.4，完整依赖由锁文件固定。
- 后端：Java21编译目标，本机运行JDK25.0.4，Maven3.9.11；PostgreSQL17.11使用本次新建的隔离库。尚未在独立JDK21运行时或Linux主机现场验收。
- 产物：`backend/target/archive-service-0.1.0.jar`，已核对包含网页入口和17个构建资源。最终程序从该标准路径启动并完成页面与小屏布局复测。
- Java服务仅监听本机18091端口；浏览器测试库与HTTP集成测试库分离，数据库仅监听本机55439端口。测试数据、凭据和截图不进入版本控制。

六组浏览器验收使用真实Java接口和真实PostgreSQL，并独立复核落库状态：

1. 登录、建档、上传中文文本附件、预览、正式归档、借阅申请、审批、借出、归还。
2. 审批中心、规则、组织、基础设置、日志和运维页面可访问；发布/阅读公告，脚本文本按普通文本显示；390px宽页面无横向溢出。
3. 审批规则新建和编辑；修改用户资料后保留已有角色关联。
4. 异常登记与处理；销毁审批后必须先勾选核对范围才能执行；仅销毁批准对象，其他档案不受影响。
5. 只读账号没有新增/销毁入口；跨部门档案不可读取；预览权限不授予下载；禁用后刷新回到登录页。
6. 延迟真实详情响应后快速切换档案，旧响应被丢弃，新对象显示正确，不混用档案主键与详情。

所有浏览器验收在最终业务逻辑版本上通过。最后一次变化仅为小屏表格CSS选择器修正，已针对受影响页面复测并重新打包；后端代码未变，不重复运行已通过的77项测试。

## 已知边界

本轮完成现有档案业务的Web入口，不扩展公司门户、公盘、整理移交、鉴定暂缓、知识库引用等后续功能。销毁为审批与业务登记，不证明实物已销毁，也不删除历史附件及备份。网页恢复入口只校验备份，实际恢复仍由管理员离线执行到新库与新目录。

正式投用前仍需公司样例与角色验收、HTTPS配置、备份保留策略、目标负载测试和Linux环境验证。几人至100人的规模是目标，当前没有100人并发压测结论。运行入口与配置见[Web部署说明](web-deployment.md)。
