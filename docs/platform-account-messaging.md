## 已实现行为

- 管理员在“组织与人员”重置其他有效账号，填写原因并验证本人密码；版本和操作号沿用现有命令事务。重复提交不生成第二个临时密码。HTTP、审计和幂等回执不返回口令。
- 初始密码与员工当前工号一致、24小时有效，登录只能设置本人密码；重置立即撤销目标员工旧会话与旧找回流程。停用账号不能重置，个人改密仍在个人中心完成。
- 登录页通过工号申请邮箱找回，向已绑定公司邮箱发送六位随机码。账号不存在、停用或受发码限额限制时，受理结构保持一致，不返回完整邮箱。
- 验证码10分钟有效，重发至少间隔60秒；同一流程累计输错5次结束，重发不清零。每账号滚动一小时最多5次、上海自然日最多10次发码；来源一小时最多100次找回请求或验证。数据库协调并发限额。
- 成功找回后重新登录；新密码至少8位，包含英文字母和数字，且不得等于工号。邮箱更换、账号停用、安全代次变化或流程结束后，旧验证码不能继续使用。
- 个人中心显示真实部门、公司邮箱和分模块角色。电脑端新增“消息服务”，供IT查询账号邮件、技术告警及人工处理状态；创建或重置成功后IT可在前端提示框查看、复制工号初始密码；不提供读取员工自设密码、验证码或服务凭据的入口。
- 账号一小时累计三次锁定，产生钉钉技术告警；同一账号一小时最多一条。告警只含系统、级别、故障类型、受控入口和事件引用。

## 通道与持久化

`MailGateway`使用Spring Mail和Angus SMTP实现，支持STARTTLS及TLS，检查服务器证书和主机名；连接、读取、写入各有10秒超时。`LOCAL_TEST`只能用于明确隔离环境中的回环地址。SMTP确认只表示服务接受，不表示员工阅读或最终投递成功。

初始和重置密码在LOCAL模式继续使用原私有本机箱，兼容已有本机开通流程；SMTP模式与邮箱找回采用事务发件箱。凭据使用AES-GCM密文，按消息ID绑定，密钥从独立安全账本的秘密按用途派生，消息发送或过期后移除队列密文。正式恢复必须保留配对的受控密钥材料，不能只恢复数据库。

账号邮件工作器与档案授权保护状态解耦，单轮最多20项。事务内通过`SKIP LOCKED`领取，网络投递在事务外完成；租约90秒，租约已失效的领取者不再发送。明确失败按1、5、15分钟重试，之后转人工。发送后断连或领取者中断时，结果记录为未知并转人工核对；SMTP Message-ID仅作核对标识，不声称精确去重。人工重试保留总尝试次数，不延长凭据有效期。

既有业务通知复用原队列、当前来源检查和权限控制，仅替换投递适配器。消息重试不重复执行审批、借出或续借。公司邮件采用固定纯文本提示和平台入口，不夹带档案标题、正文、附件或审批凭据。

钉钉按官方机器人时间戳/HMAC加签，业务响应`errcode=0`才确认成功；正式地址限定官方HTTPS接口，隔离协议验收允许显式配置的回环接收器。未配置时不伪报送达。

## 配置

配置由受限部署环境注入，后台只展示模式与任务状态，不回传秘密。默认保持LOCAL，不自动使用公司账号发送真实消息。

| 配置项 | 用途 |
|---|---|
| `IMS_PLATFORM_MAIL_MODE` | `LOCAL`或`SMTP`，默认LOCAL |
| `IMS_PLATFORM_PUBLIC_URL` | 公司部署的HTTPS平台入口 |
| `IMS_PLATFORM_SMTP_HOST/PORT` | 公司SMTP服务器及端口 |
| `IMS_PLATFORM_SMTP_SECURITY` | STARTTLS或TLS；LOCAL_TEST仅用于回环验收 |
| `IMS_PLATFORM_SMTP_FROM` | 公司发件邮箱，后缀遵守已确认规则 |
| `IMS_PLATFORM_SMTP_USERNAME/PASSWORD` | 受限服务凭据，不入仓库、命令行或日志 |
| `IMS_PLATFORM_ACCOUNT_MESSAGES_SCHEDULE_ENABLED` | 账号消息自动调度开关，默认开启 |
| `IMS_PLATFORM_ACCOUNT_MESSAGES_DELAY_MS` | 账号队列轮询毫秒，默认10000 |
| `IMS_PLATFORM_NOTIFICATIONS_ENABLED` | 既有业务邮件工作器开关，独立于账号邮件 |
| `IMS_PLATFORM_DINGTALK_WEBHOOK/SECRET` | 受控机器人地址及加签秘密 |
| `IMS_PLATFORM_DINGTALK_LOCAL_TEST` | 仅隔离协议接收器使用，正式配置保持false |

## Service API

统一使用`/api/v1`前缀、既有响应包装和同源检查。带账号的写操作仍要求CSRF，管理操作另需再验证、版本及稳定操作号。

| 方法与路径 | 访问与语义 |
|---|---|
| POST `/auth/password-recovery` | 匿名发码/重发；工号和可选flowId；统一受理结构 |
| POST `/auth/password-recovery/complete` | 匿名提交flowId、code、newPassword；成功后重新登录 |
| POST `/admin/users/{id}/password-reset` | 人员管理权限、reason、RESET_PASSWORD再验证 |
| GET `/auth/profile` | 本人真实资料、部门及当前角色 |
| GET `/admin/account-messages` | 人员管理权限；有界分页技术状态 |
| POST `/admin/account-messages/{id}/retry` | 人员管理权限、reason、RETRY_ACCOUNT_MESSAGE再验证；过期不能重发 |

数据库新增V34找回流程、发送计数、账号消息和锁定记录，V35区分累计与本轮重试次数。既有迁移未改写。
