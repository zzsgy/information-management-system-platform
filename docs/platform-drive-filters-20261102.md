# 文件描述筛选与相邻入口检查

公盘列表支持文件名称、文件格式、上传人（姓名或工号）、首次上传日期范围、所在目录名称的组合筛选，不提供文件大小筛选。日期按北京时间自然日匹配，结束日期包含整天。格式选项直接复用允许上传的 20 种扩展名，避免遗漏旧 Office、图片和压缩包格式。

筛选标签与输入框同行，提供搜索和重置。只有提交搜索才应用草稿条件，翻页沿用已提交条件；重置清空全部条件并回到第一页。所有条件在后端权限过滤后、计数和分页前执行。无目录阅读权的单文件授权仍不会暴露目录名，也不能按猜测目录名匹配该文件。

## 其他入口的检查结果

| 位置 | 检查结果与处理 |
| --- | --- |
| 顶栏公盘快速搜索 | 跳入同一个公盘查询页，保留关键词，进入后可继续使用完整筛选，不另建一套查询规则。 |
| 回收站文件和目录 | 原先完全没有筛选，目录还固定取前 200 条；增加名称、回收日期范围、保留状态、搜索和重置。文件和目录分别分页，每页 20 条，显示各自匹配总数。 |
| 档案查询与档案附件 | 按授权表示检索题名/安全题名及获权目录字段，并有资料状态范围。原件依附档案条目，本轮未将公盘上传字段套入档案授权检索。 |
| 目录维护、导入批次、扫描批次、凭据核验 | 这些入口分别管理档案目录或业务批次，使用各自的目录关键词、部门或状态条件，不是独立的公盘文件集合；本轮不混用上传描述字段。 |

## 验证

全部测试使用隔离 PostgreSQL 55450，浏览器使用 HTTPS 18456，未向日常预览写入验收人员或资料。

- `DriveLifecycleIntegrationTest#documentFiltersCombineMetadataAndDateBoundaries`：五类描述条件同时生效，姓名/工号匹配，午夜和当天最后时刻纳入、次日排除，26 条结果分为 20+6，无重复，非法日期/倒序日期拒绝，不可见文件从计数中排除。
- `recycleFiltersApplyToFilesAndFoldersAndPageCounts`：回收日期与保留状态联合匹配，文件/目录独立权限和分页，非法状态拒绝。
- `crossDepartmentDocumentGrantDoesNotExposeParentFolder`：无权目录名返回空，按目录名称搜索也不泄漏单文档授权的父目录。
- `permissionFilteredPagingRemainsBoundedWithManyVersions`：千条记录的授权分页仍通过 3 秒限时检查。
- 4 项后端测试及 16 项既有前端单测通过，Vue 类型检查与平台构建通过。
- Chrome 实际查询得到 26 份文件，第二页 6 条；错误上传人得到空结果，重置清空所有条件；回收站 25 个文件/1 个目录，文件第二页 5 条；顶栏搜索进入相同筛选。合并最新全局样式后，公盘和回收站各四个短字段均实测为 40px 高的同行布局。
