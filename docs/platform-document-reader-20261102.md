# 公盘连续文档阅读器与文件详情样式

2026-11-02，公盘阅读从一页一图的手动翻页界面改为统一的连续滚动阅读器。当前版本和历史版本共用`DocumentReader.vue`，支持页码定位、50%至200%缩放、适合宽度、滚动页码显示和Esc关闭。默认100%显示，工具栏固定，文档在独立阅读区中滚动。

页面正文沿用受控阅读接口和服务端Office转换。视口附近页面按顺序加载，为后台预览准备保留渲染名额；远离视口和关闭时释放浏览器图像。后台仍逐页核验权限及原件副本，现有5秒会话核验失败后关闭阅读器并清除已显示页面。这次不添加文本搜索或文字选择能力。

文件详情改为居中弹窗：长标题、格式/大小/版本/创建时间摘要、主要阅读入口、文件管理操作、历史版本表格分别排布。“当前版本”改成行内标记，消除旧样式中的整行色块。阅读文档、历史阅读、下载、授权、上传新版本及管理操作继续使用原接口和权限。

验收发现日常预览仍指向2026-10-28的旧渲染程序，包中缺少图片读取实现，导致独立打开PNG也报预览失败。此次通过现有Maven构建生成新处理包及lib依赖，独立目录发布；没有手工修改旧JAR。新处理包7项测试全部通过，覆盖PDF、图像边界和使用水印。业务后端254项类与资源逐项核对与原运行版本一致，数据库迁移沿用原版本。
