# 操作日志分页、分区与归档（2026-11-02验收完成）

本批只修改新平台 Java/Vue、数据库迁移与既有维护工具，保留中文注释，网页仅考虑电脑端。旧版系统不参与测试。日常数据不得导入压测夹具。

## 查询行为

- 默认最近七天，仍限制单次查询跨度不超过366天。时间及UUID均按降序排序，下一页使用元组范围定位，不再使用深OFFSET；每次只取页大小加一行。
- 默认不统计总数。页面的“统计总数”复用本人原查询票据和时间截点，显式精确统计；超时保留已有列表，不伪装为零条。总数不代表档案正文访问授权。
- 第一页返回`queryId`、`cursor`、`nextCursor`、`hasNext`及`cutoff`。下一页只提交随机`cursor`；服务端保存筛选条件、每页数量、时间截点及排序锚点，不接受调用方篡改时间、模块或锚点。上一页复用已存游标，不重新开启时间窗口。
- 查询票据及游标十分钟有效，只能原本人使用；翻页、统计、导出均按当前会话和当前角色/范围重新授权。撤权后不能凭旧票据继续读。过期票据回收时级联删除游标。
- 浏览器验收发现事务开始时间会将查询自身的审计混入原截点，导致返回上一页漂移。查询截点改为数据库真实时钟；人工、HTTP、拒绝及文件检查事实显式记录真实入库时点，界面意图使用真实接收时点。没有改写已有日志时间。补充往返翻页及跨月回执定位回归。时间函数差异参考[PostgreSQL 16文档](https://www.postgresql.org/docs/16/functions-datetime.html#FUNCTIONS-DATETIME-CURRENT)。
- 最终并发验收还复现了截点之前开始、第一页返回之后才提交的事务：仅固定时间仍可能使已浏览页面变化。`V44`在十分钟游标中保存首次返回的记录ID及下一页游标，同页读取加行锁；回看时用这些ID重新执行当前范围授权。只保存实际访问页面的有界ID，不保存正文、整份查询结果或长期数据库事务。空页也固定；权限收缩可使该页减少，不能补入原本未展示的记录。
- 查询票据不是跨请求的完整MVCC快照。统计和导出仍按原筛选、时间截点和当前可见范围独立执行，可能包含截点前写入而稍后提交的记录；不把缓存页面总量冒充精确总数。重新查询可刷新页面成员。
- `total`默认是`null`，不是0；兼容显式`includeTotal=true`。旧`page`只允许1，深页号明确拒绝，不能静默退回首页。导出仍需独立权限、本人再验证，最多一万条，超限拒绝。

## 无损分区迁移

`V43__audit_partition_lifecycle.sql`在单个事务内将事实、界面意图和范围快照转换为UTC自然月分区。迁移需要停机窗口、完整独立备份和足够的临时磁盘；大型既有库不能直接在线启动升级。获取排他锁失败会回滚，复制阶段取消普通短查询超时，逐字段`EXCEPT`及数量一致后才移除旧物理表。对已有事件编号、时间、操作者、请求号、幂等结果与范围快照不作重写。

`V44__audit_cursor_page_membership.sql`仅在短期游标元数据增加两个可空字段，不修改历史审计事实。升级前后及全量恢复后的实际验证见[专项验收记录](platform-audit-storage-validation.md)。

- `audit_identity`继续保证跨月份的事件ID、事件去重ID和操作号全局唯一；`interaction_identity`保证界面意图跨月份重放不重复。登记表也只追加并纳入备份。
- 事实与范围快照使用带时间的复合主外键，查询联接带上时间条件。月分区继承更新/删除保护，直接清空子分区也被拒绝。
- 幂等重试先经全局登记定位月份，再读取原回执，避免随着历史年数增长逐个探测分区。
- 提前建立未来十二个月，每小时维护分区日历；低频建区使用跨实例事务锁。日常查询不执行DDL。
- 封存状态在事务中与追加的`FOR SHARE`行锁互斥；先等在途追加完成，再变为`SEALED`。已封存月份禁止继续追加。

## 双副本归档

IT在“操作记录 → 存储与归档”选择热区以外的完整月份。排队需本人再验证和稳定操作号，重复提交返回原任务。默认保留最近三个热月份。

- 后台单轮领取一个月，固定500行JDBC批量游标，流式生成私有`records.jsonl.gz`，不把整月装入内存。包含事实、意图、范围快照及两类全局登记行，保留全部列。
- 两个独立目录均写入文件与清单，刷盘后逐一核对SHA-256、GZIP完整性和各表行数；两份都成功才标记`ARCHIVED`。部署方必须把两目录落实到独立介质/故障域；本机双目录演练不代表物理冗余或HA验收。
- 文件大小受上限约束，空间不足、权限失效、结果未知、缺失或损坏均不记成功。失败保留原在线记录及现场，允许新任务重试；运行租约过期转人工核对。
- **本批归档保留在线历史，不自动分离分区，也不回收主库空间。**至少三年的平台/公盘/界面保留规则不缩短，档案历史持续保留。今后冷数据移出在线库应另做可检索恢复与保留策略验收。
- 既有`maintenance.cjs`将两个归档目录纳入独立备份和恢复。检查、备份和恢复还会把已完成归档与数据库登记的摘要及清单对照，不能把受损归档重新登记为正常备份。恢复配置默认关闭本批工作器，不自动开放恢复实例。

## 容量与告警

后台按小时读取关系及索引空间、统计估算条数和已配置的数据库卷可用量，不对操作表执行全量精确COUNT。覆盖三类分区及全局登记，估算条数与精确业务查询明确区分。积累至少一小时样本后估算日增量及预算剩余天数，零增长或样本不足不编造预测。

- 日志预算默认1,000,000,000,000字节，70%预警、85%严重；数据库卷可用量低于下限同样严重。
- 未配置数据库主机真实数据卷时显示预警和“无法核对剩余空间”，不能以应用服务器卷代替远端数据库卷。
- 告警和事务发件箱同事务，当前有效IT每24小时最多一条`AUDIT_CAPACITY`。未配置正式消息通道时如实保留待投递/重试状态，不声称已经通知到公司机器人。
- 技术容量样本保留90天；该清理只处理容量指标，不清理原审计、界面记录、登记或归档证据。

| 配置 | 单位/缺省 | 用途 |
|---|---|---|
| `IMS_PLATFORM_AUDIT_STORAGE_ENABLED` | true | 建区日历、自动采样、已排队归档；不控制审计追加 |
| `IMS_PLATFORM_AUDIT_BUDGET_BYTES` | 字节/1 TB | 主库日志及索引容量预算，副本、WAL、独立备份另算 |
| `IMS_PLATFORM_AUDIT_DATABASE_VOLUME` | 绝对路径/空 | 数据库主机真实数据卷；不修改目录权限 |
| `IMS_PLATFORM_AUDIT_MINIMUM_FREE_BYTES` | 字节/5 GB | 数据库卷低空间阈值；归档目的卷另预留最大文件空间 |
| `IMS_PLATFORM_AUDIT_HOT_MONTHS` | 月/3 | 可追加热区，范围1至120，不缩短历史证据保留期 |
| `IMS_PLATFORM_AUDIT_ARCHIVE_PRIMARY/SECONDARY` | 两个绝对目录/空 | 私有双副本归档，不允许互相或与业务持久目录嵌套 |
| `IMS_PLATFORM_AUDIT_ARCHIVE_MAX_BYTES` | 字节/2 GB | 每份压缩归档硬上限；超限保留在线记录并报失败 |
| `IMS_PLATFORM_AUDIT_SAMPLE_DELAY_MS` | 毫秒/3600000 | 周期采样，同一小时只采一次 |
| `IMS_PLATFORM_AUDIT_WORKER_DELAY_MS` | 毫秒/30000 | 每轮最多处理一份月份任务 |

## 隔离验收边界

- 迁移/功能/压测端口55476，根目录`D:/tmp/ims-platform-audit-scale-20261031b`；恢复在另一全新集群55477，输出目录从未存在，不覆盖日常库、来源或独立备份。
- `AuditPartitionMigrationTest`先用正式V42空库引导，再生成历史记录并迁移，验证逐字段相同、范围快照、界面意图和跨月份唯一性。
- `AuditStorageIntegrationTest`验证游标同时间排序、翻页不重复、追加后截点、当前权限、票据归属/到期、跨月去重、子分区保护、预警去重、重复归档、双副本失败及重试、归档独立回读和内容对比。归档月份会封存，该组应在新建隔离库运行。
- `AuditScaleAcceptanceTest`仅在`IMS_AUDIT_SCALE_LOAD=yes`且55476库运行：200个禁用合成主体、100万事实与900万界面记录，十万行一事务，保留正式外键和全部触发器；JVM限制512 MB。深游标、显式统计、8读2写混合负载，以及整月双副本归档调用正式服务。数据库服务耗时不等于完整HTTP、生产硬件或HA承诺。
- 规模脚本报告路径由`IMS_AUDIT_SCALE_REPORT`指定，必须不存在；原始输出、失败诊断和最终结果分别保存，不覆盖前次证据。
