# 模块分类栏与查询布局整理

2026-10-31 按用户截图意见，将目录与保管及其他同类页面的分类切换整理为共享样式。本批仅修改电脑端显示结构、局部样式及必要的无障碍名称，不修改业务接口、授权规则或数据库。

- 九个页面共用 `theme.css` 的 `module-tabs`：目录与保管、人员交接、管理配置、流程中心、实物借还、扫描作业、运维与保护、首页管理、业务数据接入。标签统一40px高、13px字号，以品牌色文字和底部细线表示选中，移除重复的整块主色按钮及分散样式。
- 目录页查询区增加14px上下、20px左右内边距，与表头和分页对齐；查询关键词补充可访问名称。空列表复用 `EmptyState`，数量靠左、翻页靠右，分页按钮保持紧凑。
- 人员、权限等已有表格标签和通用工具栏同步收紧间距。扫描工具栏去掉面板内的重复内边距；运维、安全和扫描页面的有标题表单改为沿输入框底边对齐，修正按钮偏高约14px的问题。
- 放宽原1100px整页最小宽度，兼容960px级别的电脑窄窗口；保留原桌面导航，不增加手机端布局。
- 沿用现有网站新增、编辑弹窗，以及首页应用入口、顶部消息与反馈的位置。业务数据接入仍为界面预览。

## 验证

平台类型检查、发布构建、应用打包及16项已有前端测试通过。九个分类页面逐项核对样式，另复核组织与人员、角色与权限、操作记录和安全页面，共13页。1280宽度下完成31次分类切换，标签均为40px，无整页横向溢出或页面错误；恢复正常桌面宽度后查看目录、人员交接及运维页面。运维、安全和扫描的六处表单工具栏再次测量，输入框与按钮底边一致。

后续补充复核13个页面在960px窗口下的布局；日常目录页在实际1018px窗口中，文档内容宽度与可用宽度均为1007px，没有整页横向溢出。查询输入框距面板左侧约20px，分类标签均为40px高。隔离应用与数据库在检查后停止，日常预览保留当前IT管理员的目录页供查看。

浏览器验收使用原55475合成资料库和18575隔离网页服务，未向日常预览写入测试员工、档案或配置。隔离网页沿用当前本机平台TLS身份，不修改浏览器信任设置；账号、数据库和附件目录继续隔离。日常预览通过已有Windows后台任务发布，发布前备份数据库与运行入口，发布后核对人员任职及数据库进程保持不变。
