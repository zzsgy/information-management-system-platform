# 公盘管理弹窗与文件列表

公盘管理配置、目录维护及文件人员授权共用居中弹窗，宽度上限 1080px，标题区固定，内容超出可视高度时在弹窗内滚动。目录创建、维护、委托和人员授权使用独立卡片；创建目录按钮放在卡片底部右侧，短字段继续保持标签与控件同行。有效委托为空时显示明确空态，长目录名和动作文本换行，操作列保持可用。

公盘文件列表增加上传人、上传时间、所在目录。上传时间沿用文档首次发布时刻，追加版本和移动文件不会改写上传归属；目录显示当前实际所在目录。长目录名省略显示，悬停可查看完整名称，窄窗口可横向滚动表格。

列表接口仅对当前页关联上传人和目录，不逐文件发起浏览器请求。沿用原分页、查询条件及授权：只获单文件阅读权且无父目录 VIEW 权时，folderName 返回 null，页面显示“目录未授权”。不增加迁移，不变更保存、授权和上传流程。
