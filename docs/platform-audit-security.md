## 本批行为

- 操作记录增加公盘模块、界面操作意图、请求编号筛选及独立导出。平台 IT 查询平台和公盘记录；档案审计仍须档案角色和能力。部门档案员仅查询当前所属部门及有效任职范围；跨部门批次不得透出给单一部门。公盘部门负责人还须具有当前有效的目录管理委托。归属无法确认的历史事件只向对应模块总管理员开放。
- 审计归属通过独立追加快照记录；纸质借还、授权策略及审批证据按对象归属确定部门，不用操作人的部门代替。查询先过滤授权范围再计数、分页，不返回题名、正文、口令、令牌或内部幂等载荷。
- `PLATFORM.AUDIT_EXPORT`、`DRIVE.AUDIT_EXPORT`、`ARCHIVE.AUDIT_EXPORT` 是独立能力。模块总管理员初始化获得本模块导出能力，部门角色默认只有查询能力。导出须本人再验证，绑定查询时保存的原条件和时间截点；票据仅本人使用、十分钟有效，下载时再次核验当前会话、能力及范围。最多一万行，超限拒绝，不截断。CSV 处理公式前缀，导出本身留痕。
- 界面事件代理记录按钮、表单、选择、展开、导航、键盘提交和对话框 Escape 意图；不记录空白点击、输入值、控件文字、业务名称或 URL 参数。紧随用户动作的接口共用请求编号，后台轮询使用独立编号。服务端直接调用仍记录实际 HTTP 状态及业务事件；界面意图和 HTTP 200 都不等于业务成功或客户端完整收件。
- 登录保护复用既有规则：15 分钟内密码错误达到 5 次暂停 15 分钟，账号一小时内锁定 3 次告警。新增安全管理队列，与原正式消息发件箱连接。
- 十分钟内同账号 10 次越权/不可见访问、50 个不同文件下载或30个不同文件打印受理，触发告警及对应动作十分钟限流。下载按服务端完成输出计数；打印按有效任务受理计数，不能推定实际出纸。查看、下载和打印分别处理，已批准且完整匹配的固定批次清单不重复触发批量误报；越权仍拒绝。
- 同账号同类告警滚动一小时最多一条通知。告警和发件箱同事务，计数窗口和去重使用 PostgreSQL，避免多实例内存计数不一致。消息工作器沿用有界领取、租约、退避重试和发送结果未知转人工核对，重试消息不重复业务操作。
- IT 在“安全管理”核对告警，处理意见、处置人、时间和解除限流动作追加留存。处置使用本人再验证、并发版本和操作号，重复提交不重复处理；不会自动永久停用员工账号。
- 界面日志及平台、公盘关键日志至少三年，已生效保留期只能延长。档案及其历史证据持续保留，本期没有日志删除入口。审计事实与界面意图禁止常规 UPDATE、DELETE、TRUNCATE，处置历史禁止改写。过期查询票据每五分钟有界回收，票据清理不触及审计证据。

## 接口与结构

所有接口位于 `/api/v1`，沿用同源 Cookie、CSRF、请求大小及当前身份检查。

| 接口 | 用途和边界 |
| --- | --- |
| `GET /admin/audit-events` | 模块和时间范围必经授权过滤，默认每页20、上限100，单次时间跨度不超过366天 |
| `POST /admin/audit-exports/{queryId}` | 原查询的独立导出授权，需再验证和操作号 |
| `GET /admin/audit-exports/{queryId}/file` | 再授权后生成有界CSV；准备记录不宣称员工已保存文件 |
| `POST /me/interactions` | 固定枚举意图；每人每分钟至多300条，实际业务日志不受意图上限影响 |
| `GET /admin/security` | 按状态分页查询告警，并返回当前日志保留策略 |
| `GET /admin/security/{id}/history` | 查看不可变处置历史 |
| `POST /admin/security/{id}/disposition` | 记录核对和可选解除限流，需版本、操作号和再验证 |
| `PUT /admin/audit-retention` | 延长保留期，需版本、操作号和再验证 |

迁移 `V38`—`V40` 增加八张 `ops` 表、范围及计数触发器、独立权限和查询索引。新增表仍属于既有备份工具包含的 `ops` 模式，没有另起不受备份管理的新模式。按账号/时间窗口、模块/时间、目录、请求号及票据到期建立索引；保留原有数据库查询超时与有界连接池。

代码入口：`AuditSecurity.java`、`AuditSecurityController.java`、`Audit.java`、`HttpBoundary.java`、`Audit.vue`、`Security.vue`、`interaction.ts`。账号发件箱及钉钉适配器复用既有实现；公盘及档案实际使用出口接入计数和限流。
