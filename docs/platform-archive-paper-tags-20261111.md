# 档案登记保存类型与纸质标签

保存类型统一展示为纸质、电子、纸质+电子，内部继续沿用 PAPER、ELECTRONIC、MIXED。台账列表及筛选以该代码为准，不再依赖可自由填写的历史保存类型。

含纸质的新档案盒必须绑定纸质原件、纸质复印件中的至少一种，可同时选择两种。电子类型不接受纸质标签。标签保存在 extensionValues.paperTags，并进入登记快照；字段为系统固定字段，不允许自定义模板占用。修改标签属于关键更正，审批对比显示中文标签。

旧数据不自动补标签，不重写历史快照；无关字段维护继续允许。修改纸质信息时执行新规则。批量台账新增第19列“纸质标签”，两个标签用顿号分隔，继续兼容原18列；旧表明确填写“纸质原件”或“纸质复印件”时沿用该明确分类，仅写“纸质”时要求补标签。

本次无需数据库结构迁移。验证覆盖真实服务的两种角色、标签必填、事务回滚、数据与快照一致，以及模板往返与旧列兼容；测试使用独立 PostgreSQL 55448 环境，不写入日常业务数据。

验证结果：前端40项测试通过，类型检查及平台构建通过；Maven verify 共517项，实际执行150项通过，367项依赖其他专用环境的测试跳过。日常预览已切换至 D:/tmp/ims-platform-paper-tags-20261111-build，网页与档案模块资源 HTTP 200；数据库仍为54版。隔离测试库已停止，测试资料未进入日常预览。
