# 工号初始密码与强制改密

2026-10-31 用户确认覆盖此前随机临时密码、个人密码仅非空的规定。新建及管理员重置使用员工当前工号作为初始密码，24小时有效，首次登录只允许完成本人设密和退出。自主设置的新密码至少8个字符，同时包含英文字母与数字，不要求大小写组合或特殊符号，且不得与工号或当前密码相同。该校验同时覆盖首次设密、本人改密和邮箱找回完成入口；既有密码仍可用于登录和再次验证。

IT 在创建或重置成功后看到“领取初始密码”对话框，可以直接复制。内容仅来自本次成功操作及重新读取的待设密员工工号，关闭或离开页面清空；没有新增个人密码查询接口，不向日志、幂等回执或浏览器持久存储写入密码。未接通邮件的本机环境不再要求查找本地投递文件。
