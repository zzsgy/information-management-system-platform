# IT 配置文件处理服务

适用当前平台。更新应用时需正常执行新增迁移 `V75__managed_service_bindings.sql`；如部署脚本固定了 Flyway 目标版本，应在备份和升级确认后允许迁移至75。不要跳过数据库迁移只替换网页。

## 网页操作

1. IT 管理员登录，进入“管理中心 → 运维与保护”。
2. 在“文件处理服务配置”找到公盘文件检测、档案文件检测、人员与台账文件检测或 Office 预览与编辑。
3. 点击“配置服务”或“编辑授权 / 续期 / 停用”，填写服务名称、获准部门、截止时间、启停状态和配置原因。只勾选已批准的实际部门；“选择当前全部部门”不包含以后新增部门。
4. 点击“保存并生效”，输入本人登录密码完成再验证。系统同时保存专用身份和业务绑定，记录审计，新的绑定无需重启应用。
5. 保存后自动检查检测程序、病毒库和后台文件处理器。也可点击“检查运行环境”重新验证。授权正常但检测程序未配置时仍显示具体故障，不把文件当作检测通过。

其他角色无法查询或修改此入口。已有身份保留原ID及历史关联；配置停用不删除身份、历史任务或文件。不能用续期操作扩大模块范围。旧环境变量中的服务编号在首次网页维护前仍有效，维护后以数据库绑定为准。

## 授权配置与服务器安装的区别

网页处理“允许哪个后台服务处理哪些部门、授权到何时、是否停用”，不向浏览器返回密钥，也不接受网页指定任意可执行程序路径。以下是部署电脑的实际运行环境，必须真实存在：

- ClamAV 检测程序、对应程序摘要、官方且未过期的病毒库、私有临时目录。
- 已启用后台文件处理器；部署环境参数为 `IMS_PLATFORM_WORKER_ENABLED=true`，更改启动参数后需重启服务。
- Office 在线预览/编辑需要部署 Office 服务并配置连接和独立密钥；在网页配置 Office 身份不会自动安装或启用 Office。
- 文件存储、真实保护检查和备份状态继续使用原有规则；服务身份配置不会绕过这些检查。

如果运行环境检查未通过，页面显示具体原因、错误码及检查请求编号。修复对应部署条件后重新检查，再用实际文件验证上传、检测和发布。健康提示也会保留最近一次运行环境检查失败的原因，避免授权已保存就误报整体正常。

## 接口与生效范围

- `GET /api/v1/admin/operations/service-configurations`：读取四类固定业务服务及可选部门，不返回凭据。
- `PUT /api/v1/admin/operations/service-configurations/{id}`：创建并绑定或修改现有授权；要求操作号、当前配置版本、身份版本和绑定 `SERVICE_BINDING/CONFIGURE_SERVICE` 的本人再验证。
- `POST /api/v1/admin/operations/service-configurations/check`：对服务器既有配置执行无害样本检测，返回运行环境状态，不修改员工权限或业务文件。

公盘、档案、台账检测以及 Office 调用每次执行重新读取当前绑定；有效期、启停状态、部门和动作范围仍由后端实际检查。并发修改返回冲突，不能覆盖另一个管理员的新配置。
